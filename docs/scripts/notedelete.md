# Пользовательский сценарий «Удаление заметки»

## Действующие лица: 

1. Пользователь

2. Приложение

3. Бэк

4. База данных

## Предварительные условия 

1. В системе сохранена хотя бы одна заметка.

2. Пользователь должен находиться на главном экране.

## Выходные условия 

1. В системе удалена заметка пользователя. 

2. Заметка не отображается на главном экране.

## Основной сценарий

1. Пользователь нажимает на заметку.

2. Приложение открывает окно просмотра текста заметки.

3. Пользователь нажимает кнопку **Удалить**.

4. Приложение открывает пользователю окно подтверждения «Удалить заметку?».

5. Пользователь нажимает кнопку **Да**.

6. Приложение отправляет запрос Бэку на удаление заметки.

8. Бэк удаляет заметку из Базы данных.

9. Бэк возвращает Приложению ответ об успешном удалении заметки.

10. Приложение открывает пользователю уведомление 
«Заметка успешно удалена».

## Альтернативный сценарий № 1

1. Пользователь нажимает на заметку.

2. Приложение открывает окно просмотра текста заметки.

3. Пользователь нажимает кнопку **Мои заметки**.

4. Приложение открывает пользователю главный экран. 

## Альтернативный сценарий № 2

1. Пользователь нажимает на заметку.

2. Приложение открывает окно просмотра текста заметки.

3. Пользователь нажимает кнопку **Удалить**.

4. Приложение открывает пользователю окно подтверждения «Удалить заметку?».

5. Пользователь нажимает кнопку **Нет**.

6. Приложение открывает окно просмотра текста заметки.
